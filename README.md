# SEA TikTok weekly reports

## Repair archived AI insights

Use the existing archive and model configuration; no TikHub token is needed:

```bash
python weekly_job.py backfill --dates 2026-10-05 2026-09-14
python weekly_job.py validate
```

Without --dates, backfill checks every date in data/dates.json. Complete reports are
skipped, including on repeated execution. Missing, malformed, incomplete or
wrong-date insights are regenerated by generate_insights() from combined.json.
No videos are scraped or translated, covers and date indices are unchanged,
and no notifications are sent. A model failure returns a nonzero exit status;
existing insight files are only replaced atomically after complete generation.
Successful weeks are retained if another week fails.

The model uses the existing ANTHROPIC_BASE_URL / ANTHROPIC_AUTH_TOKEN (proxy),
or ANTHROPIC_API_KEY configuration, plus ANTHROPIC_MODEL (existing default:
glm-5.2). The SDK is declared in requirements.txt. Configure a reachable service
and an available model before running; no fallback analysis is fabricated.
Historical analysis uses that week's archived videos, generated at repair time.

If the authoritative archives exist only in gh-pages, use its checkout:

```bash
python weekly_job.py backfill --data-dir ../published/data --dates 2026-10-05 2026-09-14
python weekly_job.py validate --data-dir ../published/data
```

Add --deploy to backfill to publish repairs. This updates gh-pages only; commit
repaired source archives separately if they should also be stored in main.
Deployment clones existing gh-pages and overlays local archives, unions date
indices, and validates all indexed reports before any retention or push. It
refuses to deploy if published history cannot be read. Backfill deployment
preserves every indexed historical week. Regular Monday deployment keeps the
existing five-week limit in the staged site while retaining source archives.
Neither path force-pushes. The Monday job also checks/repairs indexed historical
insights before publishing; model failures block deployment and notification.

Validation checks nonempty video arrays, matching insight dates, nonempty
summaries, and the region/category dimensions required by the existing generator
(categories require at least five videos; present regions require overall
analysis). It does not verify the factual quality of model-generated prose.

The page shows explicit messages for absent analysis, load errors and unavailable
region/category analysis; video loading remains independent. Obsolete asynchronous
responses cannot overwrite the newly selected week's data or analysis.

## Regression checks

```bash
python -m unittest discover -s tests -v
node --test tests/test_frontend.cjs
```

Tests use temporary archive fixtures and mocked model responses, Git operations
and fetch responses; they never invoke the model, scrape videos, publish, or send
messages. Frontend tests execute the actual inline script in Node with a minimal
DOM fixture. They do not replace a browser/Pages deployment check.
